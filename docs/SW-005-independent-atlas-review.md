# Independent review of SwampWiki's scientific navigation

Enterprise Claude Opus 5.5 reviewed the published SwampWiki text release (`8c271ed`, atlas `2026-11-18-text-v1`) and sampled the Eigenquestions overview (`387e95e`). An independent Opus 5.5 xhigh pilot separately followed the LZ example on the live wiki. The project manager checked the catalog bytes against publication and independently repeated the central graph counts. Findings below separate observations from candidate changes. These are checks of one release and a limited scientific sample.

## What the review reproduced

- **Browsing reaches almost all topics through some route, while topical narrowing reaches about a seventh.** Starting from the 15 collection entrances and following only outgoing `narrower` edges reaches 279 of 1,966 non-entrance catalog destinations. Allowing uncapped catalog links in both browse directions reaches 1,961. These counts exclude the 8,473 lazily indexed paper questions. A small reachable fraction under one relation type alone does not establish that individual placements are wrong.
- **Paper examples occupy 4,619 of 10,940 presented choices on authored question pages (42.2%).** On region pages, they occupy 1,039 of 2,768 choices (37.5%). Across these two classes, 112 pages mix paper examples with narrower topics. The current adapter groups parallel records by target ID, sorts by edge class, then sorts by destination title before limiting the list. This makes alphabetical order decide which otherwise comparable source questions are visible. The same directed source, target and type recur in 72 relation groups, with 77 extra records that can supply distinct evidence. The overview sometimes renders those records as identical buttons. [Prepared navigation policy](../lib/geometry/prepared-atlas.mjs) · [Example overview](https://eigenquestions.com/atlas-overview).
- **Specific problems are distinct from the successful routes.** Two live paths, through gravitational EFTs and through a Calabi–Yau method link, converged on the same distance-and-towers destination. The KK cascade review found an existing good control in the recorded routes near the threshold decay question. The weak-gravity, distance and de Sitter samples showed overlapping pages, weak links between formulations, and foundational questions hard to reach from the expected entrance. A dedicated treatment of these conjectures should preserve different statements, hypotheses and regimes. [Original weak-gravity paper](https://arxiv.org/abs/hep-th/0601001) · [Moduli-space and distance paper](https://arxiv.org/abs/hep-th/0605264) · [de Sitter conjecture paper](https://arxiv.org/abs/1806.08362).
- **The LZ question has one ordinary browse entrance and another supported scientific context.** Both reviewers saw it as Direction 12 under “Extra dimensions and conditional quantum-gravity tests.” The LZ page offers one connection, to that question. The laboratory tests page has a reviewed contribution with role `specializes` and basis `description_checked` for the same source question (`decision:source-contribution:6b20d22f24d99b16f5fd47f0`). It appears in the lab page's evidence, so the atlas already has a basis for a second reading route. The event motivates the model in the paper. Preserve the source's limits when displaying the route. [Extra dimensions topic](https://swampwiki.com/#atlas=swampwiki&version=2026-11-18-text-v1&destination=q025-candidate-question%3A190bdf4415c78268d594ff95&lens=combined&intent=explore&relation=either) · [Model paper](https://arxiv.org/abs/2609.07138).
- **The public agent path needs its own final check.** Both public discovery indexes and agent instructions are reachable. The broad review used the sites and verified destination links. Its permissions prevented testing a live agent update. Prior consent-based renderer acknowledgment is evidence for Eigenquestions. Repeat that test for SwampWiki's own origin. The current work notes are local, and the reviewed release has no hosted submission flow for corrections. [SwampWiki agent interface](https://swampwiki.com/docs/agent-interface.md).

## Decisions for the next experiments

1. **Start with three kinds of choices the reader can tell apart.** Show topic narrowing as the default next step, then offer cross-topic relations and paper evidence in named groups. Keep direct source access in search and shared links. Combine parallel controls that reach the same destination within a list while preserving distinct reasons and proofs. Use the destination title for recognition and retain route-specific wording when it explains why to click. Compare a few real branch counts with the current list; empty slots need no filler.
2. **Pilot one intermediate region using actual literature.** Start from the LZ link and the existing laboratory contribution before creating new topics. The catalog does have a Dark Dimension region called “Dark Dimension tests and neighboring cosmic-ray and vacuum questions.” Its current focus is narrow. The reviewers identified other plausible routes through KK dark matter, neutrinos, tests and vacuum matching. Check formal scope and distinct papers to decide whether to extend this region or create a separate one. The search for an inelastic dark matter topic returned essentially one usable in-corpus case; that specific example can stay a paper facet while older adjacent work is linked as background. [Dark Dimension premise](https://arxiv.org/abs/2205.12293) · [Inelastic dark matter](https://arxiv.org/abs/hep-ph/0101138).
3. **Review scientific identity before consolidating.** Build an overview for each of weak gravity, distance/towers and de Sitter with the originating statements and explicit variants. The broad review suggests aliasing near-duplicates. Apply that only after their scopes agree. Where the physical regime changes, retain both and say how they relate. Check whether the Dark Dimension EFT dispute page should also surface the original challenge, which currently sits elsewhere in the atlas. [Original EFT challenge](https://arxiv.org/abs/2308.16548) · [Reply](https://arxiv.org/abs/2309.09330) · [Rejoinder](https://arxiv.org/abs/2404.10068).
4. **Use the same tests across fields.** Select questions and target scopes before trying the navigator. Test broad-to-fine paths, two starts reaching the same destination, useful lateral links, recovery of source qualifications, and readability at phone and desktop widths. Compare graph-only, embedding-assisted and blended ranking over identical inputs. Embedding proximity can nominate a grouping or route for inspection. Review explicit scope and sources before it becomes a scientific relation. The reviewers proposed different minimum paper counts for intermediate topics, so treat such thresholds as experimental rather than prerequisites.

The initial audit covered the full catalog mechanically, with a small scientific sample. Several routes were traced in data rather than clicked live. No independent review of every paper, no new embedding experiment, and no successful agent-to-browser update on SwampWiki were established by this audit.
