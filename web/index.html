Explore with your agent

Any agent can read the atlas’s static questions and sources. An agent with browser access or a local companion can update this page through the shared interface. Each destination has a shareable link. Use this orientation alongside independent research.

Agent instructions and supported actions

Use a local companion
  1. Get the repository and install its portable navigation skill.
  2. Start the companion using the setup instructions.
  3. Open its local browser link. Agent actions update that page automatically.

To attach this page, your browser may ask to connect to apps on this device (Local Network Access). Allow that site permission for SwampWiki to use your companion. If blocked, change the site permission or open the companion’s local link. Destination links work without a companion.
